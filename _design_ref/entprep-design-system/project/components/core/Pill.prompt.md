Stamped mono chip for tags, filters, counters and the streak count.

```jsx
<Pill tone="streak" icon="🔥">12</Pill>
<Pill tone="xp">+50 XP</Pill>
<Pill>Алгебра</Pill>
```

Tones: `neutral` / `xp` / `streak` / `win` / `premium`. Always mono + tabular-nums so counters don't jitter. `streak` tone reads as clickable/active.
