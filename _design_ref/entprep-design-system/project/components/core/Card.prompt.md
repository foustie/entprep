Cream-paper surface with ink border + hard stamped shadow. `hero` is the one bright splash card per screen.

```jsx
<Card>Обычная карточка</Card>
<Card variant="hero">+50 XP за сегодня</Card>
<Card tone="win" variant="compact">Урок пройден</Card>
```

Variants: `base` / `compact` / `hero`. `tone` (`xp`/`streak`/`win`/`premium`) tints a splash card — its text auto-switches to ink-dark. Keep one splash card per screen.
