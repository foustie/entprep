# Онбординг учителей — Школа 125 (30–60 мин)

Скрипт одной встречи. Платформа: white-label билд ENTprep (бренд школы, crest).  
Политика прокторинга: **только предупреждение + журнал**, балл не обнуляется автоматически.

## Перед встречей

- [ ] Учителя в allowlist (`TEACHER_EMAILS` / `VITE_TEACHER_EMAILS`), если список включён  
- [ ] У каждого есть аккаунт (Google / email)  
- [ ] Открыт school URL (или local preview с `VITE_TENANT_MODE=school`)  
- [ ] Sample pack: `public/tenant/sample-school-pack.json` (пока нет реальных тестов школы)

## Повестка

### 1. Вход и бренд (3 мин)
- Открыть приложение → убедиться, что видно **Школа 125** / crest, нет retail paywall «2990₸».

### 2. Учительская панель (10 мин)
1. **Настройки** → **Учительская панель**  
2. Создать класс (название + школа) → код `ENT-XXXX`  
3. При нескольких параллелях — переключатель классов / «Ещё класс»  
4. Скопировать код → ученик в Настройках вводит код и присоединяется  

### 3. Прогресс класса (10 мин)
- Средний балл, активные, слабые предметы  
- Карточка ученика: прогноз ЕНТ, слабые темы  
- **Исключить** ученика (kick) — показать и откатить при необходимости  

### 4. Свои тесты школы (10–15 мин)
1. Блок **Свои тесты** → загрузить `sample-school-pack.json` (или вставить JSON)  
2. **Назначить классу** → **Запустить тест**  
3. Ученик проходит; результат в истории  

> Реальные тесты Заказчика — когда пришлют машиночитаемый JSON/CSV (не PDF/сканы).

### 5. Прокторинг (10 мин)
**Полный ЕНТ** у ученика:

| Событие | Что значит |
|---------|------------|
| уход со вкладки / blur | переключился с экзамена |
| камера отклонена / отключена | нет камеры или стрим оборвался |
| отказ от камеры | согласие отклонено на экране stub |

- Stub: локальный PIP, **без записи на сервер**  
- Vendor (Proctorio и т.п.) — позже через тот же адаптер  
- Учитель: журнал в карточке ученика  

### 6. ИИ и дуэли (5 мин)
- Работают по школьной лицензии (без покупки Premium)  
- Месячный лимит ИИ — `VITE_AI_MONTHLY_CAP`  

### 7. Q&A + эскалация (5 мин)
- WhatsApp / контакт куратора продукта  
- Баги первой недели: скрин + email ученика + время  

## Чек-лист приёмки онбординга

- [ ] ≥1 учитель создал класс и выдал код  
- [ ] ≥1 ученик вступил в класс  
- [ ] Показан sample pack или их тест  
- [ ] Показан журнал прокторинга (хотя бы soft)  
- [ ] Учителя знают: warn+log, не auto-fail
