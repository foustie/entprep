---

Ты верстаешь экраны ENTprep — приложения подготовки к ЕНТ для казахстанских школьников 16–18 лет. Дизайн-система: **«Vibrant Game»** — энергия Duolingo + эстетика штампованной типографики. Тон: уверенный, живой, без корпоративщины.

## Стиль одной фразой
Кремовая бумага, чёрные 2px-рамки со «штампованной» жёсткой тенью, один оранжевый CTA и одна яркая жёлтая карточка на экран.

## Цвета (только эти, только из токенов)
- **ink `var(--ink)`** (#0F0F10) — рамки 2px, жёсткие тени, тёмный текст на ярких карточках. Всегда тёмный, даже в тёмной теме.
- **streak `COLORS.streak`** (#FF5A36) — ЕДИНСТВЕННЫЙ цвет действия: главная кнопка, фокус, огонь серии. Если элемент streak-цвета — по нему можно кликнуть.
- **xp `COLORS.xp` / `xpSoft` / `xpSofter`** (#FFC233 / #FFDF5E / #FFF1B8) — награда, звёзды, жёлтая hero-карточка.
- **win `COLORS.win` / `winSoft`** (#1EB854 / #B8ECC8) — только семантика успеха: прогресс, правильный ответ.
- **red #EF4444** — только ошибка. **purple** — только премиум-акценты.
- Фон: светлая тема — тёплый крем (`var(--bg)`), карточки белые; тёмная — #0B0B12, карточки СПЛОШНОЙ #22222E (не rgba!).
- ЗАПРЕЩЕНО: сырые hex в TSX (только токены/переменные), teal/коричневый, фиолетовые градиенты, серый-50.

## Типографика (3 семьи, только через `FF` и `TYPE`)
- **Display** (`FF.display`, `TYPE.h1/h2/h3/display`) — заголовки и hero-цифры. h1 26px/800 — один на экран; h2 18px/700; h3 14px/700. Межбуквенный минус (-0.02…-0.045em). Семейство идёт через CSS-переменную `--ff-display`: **RU = Unbounded**, **KK = Rubik** (у Unbounded нет казахских глифов ә/ғ/қ/ң/ө/ұ/ү/һ — переключается по `html:lang(kk)`).
- **Nunito** (`FF.body`, `TYPE.body/bodySmall/caption`) — весь текст. body 14px/1.65, bodySmall 12px, caption 11px.
- **JetBrains Mono** (`FF.mono`, `TYPE.eyebrow/statLabel/stat`) — цифры и ярлыки. eyebrow: 10px/800, UPPERCASE, letter-spacing 0.16em (`• ЕНТ 2026 •`). Любое меняющееся число — mono + `fontVariantNumeric: 'tabular-nums'`.
- ЗАПРЕЩЕНО: inline `'Unbounded',sans-serif` (только `FF.*`/`TYPE.*` — иначе казахские заголовки сломаются, минуя `--ff-display`), Inter/Roboto/Segoe UI, произвольные размеры (13.5, 15.5…) — бери ближайший из `FS`.

## Сетка и отступы
- Отступы строго по 4px-сетке: `SP` = 4/8/12/16/20/24/32. Никаких 18, 22, 28-там-где-24.
- Радиусы из `R`: 8/12/16/20/24/pill(100). Кнопки 12, карточки 12–16, hero 18, чипы pill. Никаких 6 или 10.
- Контент: mobile max 480px / padding 20; tablet 720/32; desktop 960–1080/40. Mobile-first.

## Глубина (только жёсткие тени, без blur)
- Покой: `0 3px 0 0 var(--ink)`; hero: `0 5px 0 0`; главный CTA: `0 6px 0 0`.
- Нажатие: тень схлопывается до 1px + `translateY` вниз (≈90ms). Каждый интерактивный элемент «проминается» — плоское = мёртвое.
- ЗАПРЕЩЕНО: размытые тени `0 4px 20px rgba(...)`, glass morphism.

## Тёмная тема (главный источник багов — читай внимательно)

Тёмная тема — это НЕ «инвертировать всё». Три типа поверхностей, у каждого свои правила текста:

**1. Тематические поверхности** (меняются с темой): страница `var(--bg)` (#0B0B12), карточки `var(--bg-card)` — в тёмной теме СПЛОШНОЙ #22222E, никогда rgba (полупрозрачность съедает контраст с рамкой). Текст на них — только тематические переменные: `var(--text)` / `var(--text-secondary)` / `var(--text-muted)`.

**2. Тематически-неизменные ЯРКИЕ поверхности** (одинаковы в обеих темах): splash-карточки `xpSoft`/`streakSoft`/`winSoft`, фиксированные белые/кремовые подложки (`#FFF`, `#FFFDF5`) внутри splash. Текст на них — ТОЛЬКО `var(--ink)` (заголовки) и `var(--ink-soft)` (вторичный). **НИКОГДА `var(--text)`/`var(--text-muted)`** — в тёмной теме они светлые и исчезают на светлом фоне. Это бага №1 в тёмной теме.

**3. Тематически-неизменные ТЁМНЫЕ поверхности** (ink-баннеры, чёрные CTA): фон строго `var(--ink)` — **НИКОГДА `COLORS.text`** (в тёмной теме text кремовый, и белый текст поверх исчезает — бага №2). Текст на них — фиксированный `#fff` / `rgba(255,255,255,…)`. В тёмной теме добавь рамку `var(--border-strong)`, чтобы баннер не сливался со страницей.

Прочее:
- `--ink` (#0F0F10) НЕ инвертируется — рамки и тени остаются тёмными в обеих темах. На тёмной странице карточку выделяет светлота #22222E (на 40% светлее фона), а не тень.
- Жёсткие ink-тени в тёмной теме почти невидимы — это норма; «штамп» несёт рамка. Не заменяй тень на blur/glow.
- Не делай светлые поверхности через `rgba(255,255,255,…)` поверх тёмного — получается грязно-серый. Только сплошные токены.
- Тинты вида `${color}15`/`${color}1F` на тёмном фоне почти исчезают — для чипов в тёмной теме допусти более плотный тинт `${color}28` или рамку цветом.

**Чек-лист тёмной темы** (прогоняй при любом изменении UI):
- [ ] Переключи тему и пройди экран: каждый текст читается?
- [ ] Внутри жёлтой/персиковой/зелёной splash — нет `var(--text*)`?
- [ ] Ink-баннеры: фон `var(--ink)`, не `COLORS.text`?
- [ ] Карточки отличимы от страницы (сплошной #22222E, рамка видна)?
- [ ] Графики/прогресс-бары: цвета не теряются на тёмном?

## Готовые рецепты (импортируй, не переписывай)
- Карточка: `CARD` / `CARD_COMPACT` / `CARD_HERO` (фон, ink-рамка, тень, паддинг уже внутри).
- Кнопки: `BUTTON.primary` (streak, аплифт-нажатие), `BUTTON.secondary` (белая с ink-рамкой).
- Варианты ответа: `ANSWER.base/correct/wrong` — но при переопределении цвета задавай ПОЛНЫЙ shorthand (`border: '2px solid X'`), не `borderColor` поверх (React-конфликт).
- Чипы: `PILL`; прогресс: `PROGRESS_BAR`/`PROGRESS_FILL`.

## Железные правила композиции
1. **Один streak-CTA на экран.** Второй по важности — `BUTTON.secondary` или ink-кнопка.
2. **Одна яркая splash-карточка на экран** (xpSoft / streakSoft / winSoft), текст на ней всегда ink-тёмный.
3. Eyebrow-ярлык над заголовком секции, а не декоративные точки.
4. Тексты — голосом 17-летнего казахстанца: «поехали», «квест», без «революционных решений» и «leveraging AI».
5. Всё двуязычно: каждый видимый текст — через `useT()` ключи в `ru.ts` + `kk.ts`. Никаких захардкоженных строк.
6. Тач-таргеты ≥ 44px, `aria-label` на иконочных кнопках, `:focus-visible` оранжевый.
